How it works

      
    
        
  1. The model reads the question and picks one of ~15 known actions (search listings, overdue follow-ups, mortgage calc…) with parameters.
    2. 
        
  2. Regular code runs that action against the database, so the numbers are always exact.
    3. 
        
  3. The model writes a short answer from the result. Questions that don't fit an action go to free chat with a compact copy of the data.
    4. 
      

      
Claude setup: deploy the realtor-ai function, then paste its URL and your project's anon key above (or into the two constants at the top of the script, so every device gets them).

      
Llama setup: install Ollama, run ollama pull llama3.1:8b, then allow this page to reach it by setting the environment variable OLLAMA_ORIGINS=* (or your GitHub Pages URL) and restarting Ollama.
